# Chemistry Lab Diagram Editor 規格書

## 專案目標

建立一套以 HTML、CSS、JavaScript 開發的化學實驗器材演示圖編輯器，用於快速建立教材、教學與實驗示意圖，而非物理模擬。

---

# 技術需求

- HTML
    
- CSS
    
- JavaScript（ES Modules）
    
- Node.js 開發環境
    
- Chromium 瀏覽器
    
- 可使用成熟開源函式庫（npm 安裝）
    
- README 中需說明函式庫選擇原因
    

---

# 專案需求

- npm install
    
- npm run dev
    
- 可直接啟動
    
- 模組化架構
    
- 完整 README
    
- 無 TODO
    
- 易於擴充
