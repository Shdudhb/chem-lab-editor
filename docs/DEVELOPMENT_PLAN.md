# Development Plan

## 開發原則

- 採分階段開發。
    
- 每個 Phase 都必須可執行、可測試。
    
- 完成一個 Phase 即停止，等待使用者確認。
    
- 不可一次完成整個專案。
    
- 僅修改本階段必要檔案。

# 每次回覆格式

1. 本階段目標
    
2. 本階段完成內容
    
3. 修改或新增的檔案
    
4. 完整程式碼（僅新增或修改的檔案）
    
5. 測試方式
    
6. 已知限制（若有）
    
7. 等待使用者確認後再開始下一個 Phase
